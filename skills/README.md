# Hackathon skill shortlist

Research date: 2026-11-06.

## Skills used by teams that placed

The organizer names these skills in its [BuildSprint 2026 results](https://blogs.latentforce.ai/blogs/buildsprint-2026-winners-blog).
The results document skill use and placement. They do not measure the effect of each skill on the score.

| Skill | Reported use | When to try it |
| --- | --- | --- |
| [frontend-design-review](https://skillpatch.dev/skill/frontend-design-review) | First prize. [Canopy](https://github.com/agentsc07/Canopy) used it on its dashboard. | Review the main demo screen for clear actions and accessible controls. |
| [fastapi-router-py](https://skillpatch.dev/skill/fastapi-router-py) | Second prize. The [NER command center](https://github.com/Ranjit1401/NER) team used it during the build. | Add or review routes if the project uses FastAPI. |
| [agents-md](https://skillpatch.dev/skill/agents-md) | Second prize. The NER command center team used it during the build. | Update shared agent instructions as project commands and rules change. |
| [frontend-ui-dark-ts](https://skillpatch.dev/skill/frontend-ui-dark-ts) | Second prize. The NER command center team used it during the build. | Build a dark React and TypeScript dashboard if the design calls for one. |

## Other skills to consider

- [demo-video-pipeline](https://skillpatch.dev/skill/demo-video-pipeline) automates narrated demo videos. The organizer reports that the [ShipShow winner](https://blogs.latentforce.ai/blogs/buildsprint-2026-winners-blog) published this skill from the project.
- [pitch-timebox](https://github.com/zghanw/hackathon-skills#what-you-get) drafts a timed pitch and rehearsal plan. The repository shows a fictional example. I found no public placement tied to its use.

## Try a skill

1. Choose a task with a clear result, such as finding problems in one demo screen.
2. Read the skill instructions and any scripts before adding it to the project.
3. Check the result against the event rules and judging criteria and record whether the skill helped.

This list links to the skills for review.

## Installed UI skill

The route preview uses [frontend-design-review](../.agents/skills/frontend-design-review/SKILL.md).
The skill is stored in `.agents/skills/frontend-design-review/` for local agent use.
It came from the [SkillPatch package](https://skillpatch.dev/skill/frontend-design-review) on 2026-11-06.
The package keeps its original acknowledgments.

The preview uses a light map and a compact route panel.
The review checks clear actions, keyboard focus, mobile layout, source labels, and playback controls.
